# TailwindScore

TailwindScore 是一个基于 PHP、Tailwind CSS、TypeScript 和 WooCommerce 的轻量级 WordPress 主题基线。

## 当前目标

- 保持模板结构清晰直观
- 用 Tailwind CSS 替代 Bootstrap
- 用 TypeScript 替代 jQuery
- 由主题统一接管 WooCommerce 前台样式
- 以渐进增强方式处理商城交互

## Phase 1 范围

- 基础主题结构
- Vite 构建与资源清单
- 站点通用模板
- WooCommerce 核心模板覆盖

## 本地开发

```bash
npm install
npm run build
npm run typecheck
```
